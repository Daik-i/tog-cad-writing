# 验证、实验叙事与图表

以下为实验设计建议。仅在实验确已进行后，才能写入正文为结果；按用户实际贡献选择对应检查。

## 1. 先按主张选择证据

| 本文主张 | 首选证据 | 不足的替代 |
|---|---|---|
| 扩大有效输入类 | 定义、理论/构造条件、该类的覆盖实验 | 更多漂亮例图 |
| 精确谓词或构造 | 表达式和误差分析、认证 fallback、实现核对 | 普通输入未出现失败 |
| 更快 arrangement | 同任务、同输出目标、阶段计时、交对/构造规模、复杂输入 | 只测完整 CAD 流程而无法定位收益 |
| 更快完整布尔 | 求交、标记、提取和转换的端到端计时 | 只测三角形求交内核 |
| 更好并行性 | 相同数值模型和配置下线程 scaling、内存与同步成本 | 本文多线程对基线单线程却归因于算法 |
| CAD 拓扑更可靠 | 小环/切触/边界/重叠分类、参数域与三维输出核对 | 只有 mesh 布尔成功率 |
| 可连续级联 | 指定内部/导出表示的长序列实验，误差及复杂度演化 | 每帧原输入独立重算 |
| 严格几何保真 | 定义度量、参照对象、证明或可靠误差测量 | 视觉接近或少量采样 |

## 2. 基准台账

最低限度记录：

- 原始数据版本/来源、选取规则、输入有效性判定、去重和排除原因。
- 实际输入数、对象对数、运算数分别统计；同模型上的 union/intersection/difference 不自动算三个独立模型。
- 原始与修复/清理/量化后的数据分开；注明修复是否改变任务。
- 单模型/双模型、n 元、深 CSG 树、交互帧、局部 CAD 小样例分别分组。
- 对每个基线给出代码版本/commit、编译优化、内核、数值设置、容差、线程、机器与资源限制。

同一数据集可能按 PWN、有效 PLC、自交或共同成功等规则选取不同子集。核查数据版本、预处理、过滤规则与统计单位，不能直接合并不同论文报告的数字。

## 3. 成功定义与独立验证

把以下状态分开报告：输入不满足前提、正常成功、崩溃、超时、内存耗尽、输出文件无效、几何/拓扑检查失败、验证器无法判断。

按输出语义选检查：无意外边界、定向一致、退化/重复元素、自交、局部流形性、空腔保留、区域归属、参考布尔等价、CAD 边界一致。验证器也有前提与数值模型，应说明其版本和限制。

**必要条件不是充分条件。** 若只验证边界闭合和无自交，正文就报告这两项，不写“证明结果为正确实体”。

没有可靠 ground truth 时，可组合理论、独立实现、精确几何核验和诊断性样例。体积相等、渲染相同或没有崩溃不能单独证明布尔正确。

以下可作为条件成立时的补充一致性检查，不替代证明：A∪A、A∩A、A\A；交换输入后对称运算结果；同时刚体变换；不同排列的 n 元输入；单次与等价表达式的几何结果。浮点实现不应默认逐位一致，非正则集合与接触语义也须先统一。

## 4. 性能统计

- 同时给完整有效任务集合的成功/失败分布和共同成功子集的时间比较；不要只留下有利样本。
- 选择适当的中位数、分位数、CDF/性能曲线、逐实例对比；平均值或几何平均需说明定义与分母。
- speedup 使用同一实例的时间比或说明聚合方法；不能把平均时间比和平均逐实例加速比混用。
- 超时和错误不是零秒；单列或按明确的删失规则呈现，不能纳入普通几何均值。
- 最大规模与难例应给输入、交对、输出复杂度及峰值内存，而非仅面数。
- 端到端计时明确是否含 I/O、预处理、量化、数据结构构建、属性传递、导出、验证；有排除项就另列。
- 交互性报告延迟分布、机器、模型规模、动态场景和是否复用缓存；FPS 与延迟的转换只在计时边界一致时使用。

## 5. 有意义的机制实验

以用户声称的贡献为准选择：

| 机制 | 可控制的比较 | 可解释的量 |
|---|---|---|
| 局部点去重 | local/global × serial/parallel | 点规模、排序成本、同步开销 |
| 新谓词表示 | 保持算法和线程相同，替换实际表示 | 各过滤阶段调用/通过率、exact fallback 成本 |
| 空间结构/提前终止 | 相同任务和其他设置下改变结构/准则 | 构建时间、冗余候选、叶规模、总时间 |
| CAD 保守检测 | 有/无相关检测或合法替代 | 受控小环/切触覆盖、假阳性、成本 |
| 容差/分辨率 | 容差与尺度交叉变化 | 曲线误差、拓扑错误、运行时间 |
| 输出简化/保持内部表示 | 有/无步骤，且验证几何语义 | 深树三角形增长、舍入失效、总成本 |

将 local/global 与 serial/parallel 的影响分开，结合过滤阶段统计解释机制；结果必须来自当前实现的真实实验。

## 6. 图表怎样承担论证

按需要选择：

1. teaser：实际输入范围、最终结果和关键难点；数值可追溯。
2. 方法图：同一个简化案例的表示/邻接/标签/输出，颜色语义始终一致。
3. 病态配置图：共面、共边/共点、嵌套空腔、近退化、不同尺度，标出为什么难。
4. 正确性图：局部放大、切片、边界或法向/参数域标注，使错误可见；不只用材质遮盖差异。
5. 性能图：说明完整集合/共同成功集合、坐标单位、对数轴、失败标记、超时限制。
6. 机制图：过滤通过率、阶段 profile 或参数敏感性与贡献一一对应。
7. 限制图：真实失败、前提不成立或分辨率边界；说明是哪一种。

选择图表服务于主张，不要求所有论文都有七种图。CAD 图尽量配对 3D 和参数域诊断；可视图不能替代计算检查。
