# 三维布尔论文的技术契约

以下为三维布尔与 CAD 求交的写作检查。按实际方法选择；每条技术结论需要相应定义、条件和证据。

## 1. 输入、运算和输出分开写

先明确对象，再讨论性质。可以用一个紧凑段落，不必机械创建小节。

| 项目 | 核实内容 | 常见误写 |
|---|---|---|
| 输入表示 | triangle mesh/soup、凸多边形集合、平面表示、隐式函数、修剪 NURBS B-rep | 全部笼统称 mesh |
| 输入语义 | 定向、闭合、PWN、流形、自交、退化、重复面、嵌套空腔 | “arbitrary meshes”省略实际前提 |
| 运算语义 | binary / variadic、任意布尔表达式、regularized 或其他集合约定、边界接触 | 把所有零厚度接触都视作数值错误 |
| 数值输入 | 输入浮点数作为精确有理数、量化后的平面、隐式交点、容差曲面 | “exact”没有参照对象 |
| 输出表示 | exact vertices、double mesh、polygon soup、三角网格、B-rep | 中间数据结构有效就称最终文件有效 |
| 输出属性 | 方向、边界闭合、流形、无自交、空腔、属性溯源、可重复使用 | 水密等同流形，或等同正确布尔 |

区分 PWN、solid mesh 与 polyhedron 等输入语义。组合缝在几何上闭合不表示支持任意孔洞；实体边界也不必是流形。根据方法自身定义说明允许的接触与退化。

## 2. 保证分层

| 性质 | 可写结论需要什么 | 不足以推出该性质的证据 |
|---|---|---|
| exact predicates | 对已定义输入与构造表达式给出符号判定的数学依据、过滤失败后的正确路径 | 普通 double 运算、经验 epsilon、过滤大多成功 |
| exact constructions | 新交点/几何对象具有精确表示，并说明表示的闭包与数值范围 | 仅精确判定相交 |
| consistent topology | 同一构造在相邻元素中一致、退化完备处理、邻接/区域标记正确 | 交点坐标精确但拼接逻辑未核对 |
| geometric preservation | 指明原几何或量化几何、精确或容差；保持面集合还是连接关系 | 视觉无差异、拓扑等价 |
| watertight output | 对当前输出表示定义边界条件与核验方式 | 无肉眼裂缝、无自交 |
| manifold output | 顶点/边 link 等局部条件及任务允许的接触语义 | 闭合或正体积 |
| intersection-free output | 精确/可靠的交叉验证及允许的共享元素语义 | 没有崩溃，或仅靠渲染 |
| reusable output | 下一次输入前提仍成立；中间格式和舍入策略明确 | 单次操作成功、逐帧从原始输入重算 |

数值内核、完整算法与文件导出是不同保证层。内部精确表示、整数范围与舍入出口分别核查，不从其中一层替其他层作保证。

## 3. 数值方法写清楚哪里发生近似

描述“实际存储什么—需要判定什么—如何计算—什么时候回退—输出如何表示”。只写方法真实使用的阶段。

- 浮点过滤：给出被认证的量及误差界；区分静态、半静态、区间与 expansion 等实际实现路径。
- 间接谓词：说明交点由哪些原始元素定义，后续谓词是否仍保持对这些元素的依赖。
- 有理数/精确构造：说明增长、延迟求值、线程行为和舍入出口；不假定所有库版本有相同线程限制。
- 固定位宽/整数齐次表示：给出输入量化、范围界、溢出条件及输出转换。不要把对量化表示的精确计算描述为对任意原始几何零误差。
- 符号扰动：说明扰动消除哪种不唯一性、是否改变几何/仅选择组合结果，避免统一称为 numerical perturbation。

用过滤阶段统计和局部化实验解释性能机制；认证过滤仍需要算法自身的误差界与正确回退。

## 4. arrangement 管线

按真实算法选择这些职责，不必固定为四阶段：

1. 发现候选相交对；区分 broad phase 的保守性与窄阶段判定。
2. 构造交点/交线，处理共面重叠、重复点和一致剖分。
3. 建立 patch/edge/cell 邻接；处理不相连但互相嵌套的组件。
4. 定义内外或 winding-number 标签，明确种子、传播或射线规则。
5. 按集合表达式提取边界，修正方向，传递来源/属性。
6. 导出目标表示并核对导出后的条件。

标出真正新增的层。交点处理改进不自动构成完整 B-rep Boolean 系统；剖分、邻接结构和表达式分类各自承担不同职责。

## 5. CAD / 混合表示分支

把连续曲面、离散网格、参数域与 B-rep 拓扑之间的接口作为独立论证对象。

写作时追踪以下实际存在的接口：

- 曲面参数域、三维几何、离散网格之间存储何种对应；离散化是否保留 face/edge/UV 来源。
- 网格近似误差是单向还是双向、使用什么度量、全局还是逐片容差；“bijective”必须限定映射的对象与域，不能仅凭采样点对应使用。
- 普通网格相交为什么可能漏掉曲面相交；是否有保守候选检测、小环种子或切触处理。
- 从网格交点到曲面交点的优化如何初始化、收敛失败如何处理、越出修剪域如何处理。
- 是一般一维交曲线、孤立交点、切触曲线，还是容差定义的二维重叠区域；不要用同一语义覆盖全部。
- 网格结果如何转换为裁剪曲线和 B-rep 拓扑；3D 曲线、两侧 p-curve 与共享边误差是否一致。
- 局部 refine、patch 边界、共面/重合和多实体公共交点有哪些已覆盖和未覆盖情况。

将表示对应、离散误差、连续优化和回写串起来。映射正则性、边界元素与局部误差需要对应条件；单向 surface-to-mesh 距离界不能自动改写为双向 Hausdorff 界。多体公共交点、小环尺寸及间距相对网格分辨率的限制，应与摘要和贡献合读。

分别描述参数域拓扑确定、曲线追踪、提升与裁剪。分析其他方法时，保留观察到的失败与推测原因之间的区别。

## 6. 曲线/曲面包含查询

对修剪 NURBS 的 GWN 场求值，明确数学重写、数值求积和近曲面/边界处理。用户容差不自动等于逐位精确的几何谓词；对不水密输入提供包含定义，也不意味着已修复几何或构造合法布尔边界。

若自适应折线仅保持当前查询点的 GWN，不应宣称保持整条曲线的所有几何性质。离散曲面上的 winding 还可能涉及不围成区域的环，不能直接把曲面标签解释为三维实体内部。

描述表示时指明实际对象。B-rep/mesh 混合、直接 CSG 渲染和 surfel 边界操作有独立输入输出契约，不能仅凭 Boolean 一词归为同一端到端算法。

## 7. 迭代与交互

区分：

- 每帧从原始输入重新求单次布尔。
- 同时执行 n 元表达式。
- 精确内部表示下求深 CSG 树。
- 每次导出浮点网格后，将文件作为下一次输入。
- 修改/变形导致输入可能违反前提，再做布尔。

主张交互性需要机器、线程和规模；主张级联可靠性需要说明表示是否闭合以及误差/复杂度如何累积。只在内部整数表示保留时成立的保证，不应扩展到中间导出 double 后的序列。
