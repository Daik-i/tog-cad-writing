# CAD 评估与图表的选择

以下是按研究契约提出的评估建议，不是所有来源论文统一采用的协议。选择能支持用户实际贡献的项目，不机械要求全部开展。三维布尔专项见 [evaluation.md](evaluation.md)。

## 主张到证据

| 主张 | 有用证据 | 不能独立支持的结论 |
|---|---|---|
| 更好的曲面表示 | 表达能力、连续性/正则性、局部编辑、自由度、评估与转换成本 | 渲染平滑不能证明 C^k 或有效 B-rep |
| 更好的拟合或重建 | 同参考/采样规则下误差分布、最大误差或认证界、锐特征/边界/拓扑 | Chamfer 小不能推出拓扑正确 |
| 参数化/网格更稳健 | 有效输入、Jacobian/覆盖/自交/奇点、失败分布、提取和导出检查 | 内部能量低不能推出全局单射 |
| 优化更好 | 相同目标/约束的基线、初始化、残差、目标值、求解时间与多初值 | 多次找到好结果不能证明全局最优 |
| 设计工具更有效 | 匹配任务的完成率、建模时间、操作/修正数、质量和用户反馈 | FPS 高不能推出易用性 |
| 结构设计更优 | 相同材料/载荷/边界/体积条件、独立力学验证、网格收敛与误差 | 柔度下降不能自动推出强度提高 |
| 工艺更可行 | 工具/设备/厚度/间隙/装配限制、碰撞/可达性、实物与测量 | 理想几何可行不能推出实物必然成功 |
| 学习辅助 CAD 有效 | 原始模型级数据隔离、分布外/噪声实验、特征与最终几何分别评估 | 几个好看输出不能推出有效 CAD 生成 |

## 让实验能被解释

数据台账区分模型、patch、查询点、操作和用户任务；同一零件的多个视图不计作独立零件。说明 CAD 清理、重采样、离散化和单位归一化改变了什么。对质量与性能采用相同输出目标，或清楚分层。

优化实验固定对比的输入、目标、硬约束、权重/归一化与可行性容差；说明初值、随机种子和终止标准。用残差与质量共同评估，不只展示能量曲线。分开预计算、求解、交互更新和导出时间。

制造记录材料、尺寸、设备/工具、加工或打印路径、后处理、连接与装配方式。报告仿真与实物测量之间的误差、重复次数和失败。是否需要测量取决于声称的结果；概念性建筑示例应标为设计示例，不包装为已建造验证。

用户研究若实际开展，说明参与者经验、任务分配、顺序与训练、可比工具、完成标准和统计单位。没有此类研究时，只报告系统功能、延迟与演示任务。不要虚构人数或用来源研究的数据代替。

## 图表按论证职责选择

- 表示/流程图：同一实例展示输入、控制变量、约束和输出；颜色具有稳定含义。
- 几何诊断：参数域和三维配对；曲率、Jacobian、接缝、误差、边界或局部放大针对实际主张。
- 可行性与质量：成功率、约束残差、质量分布、失败类型分别报告。
- 控制与消融：固定其他项，改变目标、约束、初始化、分辨率或工艺参数，解释机制。
- 制造图：设计、路径/装配、实物、测量或变形对比；标明尺度、载荷与显示放大。
- 用户流程图：真实步骤、自动与手动部分、编辑前后结果；不把示范操作当统计性证据。

用图表展示平面构件、模具/面板约束、加工路径与工件之间的连接；图表应服务实际主张，物理结论仍需对应验证。

理论图与数值图应注明采样或近似。误差热图的颜色范围、单位和截断值固定并解释。超时/无效输出不能记为零误差或零秒；共同成功子集与完整集合的结论分别写。
