# CAD 论文的研究契约

以下为写作与审读建议，按实际方法选择。各性质需要作者自己的定义、证明或实验支持，不代表所有 TOG 论文遵循统一顺序。

## 表示贡献：从性质组合解释表示选择

先说明表示支持的操作，再给出定义和性质。高阶连续、显式正则参数化、局部支撑、控制点线性依赖和视觉质量应分别陈述，不能由一个笼统的 smooth 代替。

| 对象 | 写作时明确 | 应避免的混同 |
|---|---|---|
| 样条/多片曲面 | 次数、节点、多重节点、patch 域、特殊点、边界约束 | 普通点的连续性推广到所有奇点 |
| 几何与参数连续性 | C^k / G^k 的对象、跨片重参数化、正则性 | 法向看似连续等同 C^2 |
| 控制与局部编辑 | 支撑域、自由度、可控变量、编辑会改变什么 | 控制点少等同编辑更容易 |
| 近似 | 参照对象、误差方向/范数、采样或认证、边界和锐特征 | 平均误差小等同最大误差有界 |
| 表示间转换 | 几何等价/近似、拓扑、可逆性、保留属性 | mesh 转样条即得到合法 CAD solid |

离散可展准则、交互设计和连续样条导出是不同阶段。核实离散性质是否传递到连续输出，导出后是否仍满足对应条件。

## 参数化与网格：可行域先于质量排名

明确源域和目标域、边界条件、允许改变的连接关系、奇点以及每个有效性条件的检查方法。局部 Jacobian 正、全局无覆盖、无自交、体单元有效与边界符合是不同结论。

按实际方法区分方向场构造、参数化、整数/周期约束、量化、提取网格与拟合高阶片。阶段之间需要独立契约。全局/局部优化描述的是作用范围，不自动意味着全局最优或局部单射。

若声称高阶元素沿轨迹持续有效，证据应覆盖元素内部与整个运动区间，而不仅节点或离散时间。能接收非流形输入、局部失败后仍可返回结果、对该类输入始终完整成功，也应分别描述。

## 几何优化：设计意图如何变为变量和约束

交代变量及其空间、能量每一项对应的设计意图、硬约束与软罚项、权重归一化、初始化、停止准则、不可行输入及结果残差。非凸优化中，收敛到驻点、找到可行解、经验上更优和全局最优分别表述。

有限时间采样只有在相应理论条件成立时才能支持连续性质。局部理论界不自动保证初始化可行、优化必然成功或整条管线无碰撞。几何性质分析、连续优化和整数规划若解决不同问题，分别给出变量、约束和目标。

声明近似模型的适用区间。简化模型中的关系不能无条件写成原问题的精确等价。

## 交互建模：从用户操作到求解器结果

先写工作流中的具体障碍、可用输入与操作，再解释几何约束如何表达意图。视角切换、语义标注、特征粘贴或 base/detail 分解应与其解决的设计任务连接。

分开用户输入、自动推断、人工修正及离线预处理。交互性由对应硬件与任务延迟支持；用户效率、成功率、可学性和偏好需要各自的研究证据。没有用户研究时只报告算法延迟与操作示例。探索性试用与对比研究分开；工作流评估与表示能力覆盖也分别论证。

## 制造与结构：几何约束到实物之间的链条

解释几何限制为何服务工艺：平面性可以对应构件加工，面板参数可以对应模具复用，刀具几何可以对应运动路径和表面质量目标。所述工艺能力仍需用户方法自己的验证。

| 层次 | 需提供的证据 |
|---|---|
| 几何可实现 | 定义与约束、残差、连续/离散对象、拼接与交叠 |
| 物理可行 | 材料/载荷/边界条件、物理模型与离散化、独立仿真 |
| 工艺可行 | 设备轴数/刀具、碰撞与可达性、厚度/间隙、连接与装配 |
| 实际制造 | 原型、工艺参数、测量、容差、失败和仿真差异 |

单独处理厚度与偏置。理想铰链、零厚度折叠、几何可展或面板复用不能替代材料、接头及机器限制的验证。结构优化目标须具体，如体积、质量、柔度或应力；这些目标不必具有相同最优解。

仅优化受限工具姿态并在样例中找到无碰撞位置，不等于处理了一般机床规划或加工物理。预先指定曲面分解组合、未处理连续展开或重叠，均应写入适用边界。

## CAD 特征估计与重建

把点云、曲线网络、隐式场、参数片、面-边-点拓扑和完整 CAD solid 区分。预测精度不自动给出拓扑一致、可编辑参数历史或可制造输出。

数据划分按原始 CAD 模型、零件或家族核查，避免同一模型的 patch、扫描或增强版本跨训练测试。特征回归、分类、曲线提取和 CAD 重建分别选择指标。具体结论依照实际方法与原文核查；相邻任务的经验不能替代当前任务的验证。
